# E-Commerce-Analysis-Dashboard
A dual mobile-friendly dashboards for an E-Commerce dataset using Excel, Power Query, and Power Pivot with UI/UX principles.

### 📅 Project Timeline
* **Development Period:** October 2026 .
* **Note:** This project was developed locally and later migrated to GitHub .

This Project is a comprehensive data analysis for an Ecommerce dataset built entirely in Microsoft Excel. What makes this project special is the focus on user experience and audience targeting. Instead of a single, cluttered view, I built two distinct, mobile-friendly dashboards (9:16 aspect ratio) from the same dataset to serve different business needs.

## Tools I Used
- Microsoft Excel
- Power Query
- Power Pivot

## Project Workflow
Here is how I built this project from raw data to the final mobile views:

1. Data Cleaning and Preparation
I started by importing the raw dataset into Power Query[cite: 6]. I spent time cleaning the data, adjusting formats, and making sure everything was ready for analysis before moving forward.

2. Defining the Objectives
Before building anything, I defined the core questions we needed to answer. I realized that the Executive board needs different answers than the Operational managers, which led to the dual-dashboard approach.

3. Data Exploration
I used Pivot Tables to dig into the cleaned dataset, exploring trends, checking initial numbers, and getting a feel for the story the data was telling.

4. Data Modeling and Measures
Using Power Pivot, I built a robust data model. I created custom DAX measures to accurately calculate specific KPIs for both high-level tracking and detailed operational analysis.

5. Designing the Mobile Dashboards
Finally, I built two separate dashboards using Pivot Tables, specifically designed with a 9:16 aspect ratio for easy viewing on mobile devices:

- **Executive Performance Dashboard (Macro View):** Designed for the High Board. It focuses on top-level metrics like total sales, total profit, average profit margin, and overall customer count, along with high-level trends across time .
- **Operational & Detailed Analysis Dashboard (Micro View):** Designed for managers and operational staff. It dives into the details, tracking metrics like quantity sold, average shipping cost, discount rates, and customer login types.
